Network Protocols

What is a Network Protocol?
A network protocol is a set of rules that allows computers and other devices to communicate and exchange information over a network.
Examples include TCP, UDP, HTTP, HTTPS, and DNS.

Types of IP Addresses
IPv4
IPv4 is a 32-bit address used to identify devices on a network.
Example: 192.168.1.10

IPv6
IPv6 is a newer addressing system designed to provide more IP addresses.
Example: 2001:db8::1

Public and Private IP Addresses
	•	Public IP: An address used to identify a network on the internet.
	•	Private IP: An address used within a local network.

IP Address vs Port Number
	•	IP address identifies a device.
	•	Port number identifies a particular service or application running on that device.

TCP and UDP

TCP
Transmission Control Protocol is connection-oriented. It establishes a connection before transmitting data and provides reliable delivery.

UDP
User Datagram Protocol is connectionless. It sends data without establishing a connection first and does not guarantee delivery.

Why Network Protocols Matter in Cybersecurity

	•	Detect suspicious communication.
	•	Identify unusual network connections.
	•	Investigate possible attacks.
	•	Monitor data transfers.
	•	Identify potentially malicious services.
